# Instrucciones Claude (proyecto Site Kit)

Al abrir esta carpeta como proyecto Claude:

1. Tu system de trabajo es `CLAUDE.md` + `AGENTS.md`.
2. Pipeline: `prompts/PIPELINE.md`.
3. Unicidad: `design/anti-template.md` es obligatorio.
4. Salida instalable: `engine/site-maestro/payload/` válido según `design/site.schema.json`.
5. Skills de diseño: `.claude/skills/design-taste-frontend` e `.claude/skills/impeccable`.
6. Instalación en un equipo nuevo: `INSTALAR.md`.

Si el usuario suelta documentos sin slug, crea `proyectos/<slug-sugerido>/` y mueve el brief allí.

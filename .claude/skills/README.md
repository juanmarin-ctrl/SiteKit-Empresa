# Skills incluidas en el kit

Claude Code carga automáticamente las skills de esta carpeta al abrir el repo (skills de proyecto).

| Skill | Versión | Licencia / origen | Uso en el kit |
|-------|---------|-------------------|---------------|
| `design-taste-frontend` | tasteskill v2 | Terceros — ver su `README.md` | Dirección de arte del concepto y mockup |
| `impeccable` | 4.8.0 | Apache 2.0 (terceros) | Pulido, crítica y auditoría del mockup |

Son copias de terceros para uso interno del equipo. Para actualizarlas, sustituye la carpeta por la versión nueva y haz commit.
No edites estas skills para meter reglas del kit: las reglas propias van en `CLAUDE.md`, `AGENTS.md` y `design/`.

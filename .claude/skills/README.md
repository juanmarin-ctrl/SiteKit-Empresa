# Skills incluidas en el kit (obligatorias)

Claude Code carga automáticamente las skills de esta carpeta al abrir el repo (skills de proyecto).

| Skill | Versión | Origen | Uso en el kit |
|-------|---------|--------|---------------|
| `emil-design-eng` | — | Emil Kowalski — emilkowal.ski/skill | Motion, componentes, detalles de polish |
| `impeccable` | 4.8.0 | impeccable.style (Apache 2.0) | Tipografía, espaciado, jerarquía, auditoría y polish |
| `design-taste-frontend` | tasteskill v2 | tasteskill.dev | Dirección de arte, referencias, criterio visual; lint + inspección |
| `wordpress-elementor` | — | jezweb/claude-skills | Plantillas y edición Elementor |
| `wordpress-setup` | — | jezweb/claude-skills | Conexión WP-CLI / REST al WordPress del cliente |
| `wordpress-content` | — | jezweb/claude-skills | Páginas, entradas, medios y menús vía WP-CLI / REST |

MCP complementarios (en `.mcp.json`): **Figma** (referencias de diseño) y **Playwright** (abrir, probar y revisar la web).

Son copias de terceros para uso interno del equipo. Para actualizarlas, sustituye la carpeta por la versión nueva de su origen y haz commit.
No edites estas skills para meter reglas del kit: las reglas propias van en `CLAUDE.md`, `AGENTS.md` y `design/`.
